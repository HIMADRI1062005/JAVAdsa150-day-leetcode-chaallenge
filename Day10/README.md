Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Find Minimum in Rotated Sorted Array  
🔗 https://leetcode.com/submissions/detail/1986997687/
**What I did:**  
Tried to find the minimum element in a rotated sorted array.

**Approach:**  
Used Binary Search. Compared mid element with right to decide which half contains the minimum.

**What I learned:**  
- Binary search on modified conditions  
- How to work with rotated arrays  
- Reducing time complexity to O(log n)
