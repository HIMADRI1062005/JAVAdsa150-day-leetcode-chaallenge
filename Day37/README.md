Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Search in Rotated Sorted Array  
🔗 https://leetcode.com/problems/search-in-rotated-sorted-array/

**What I did:**  
Tried to find a target element in a rotated sorted array.

**Approach:**  
Used Binary Search with modified conditions.  
At every step, checked which half of the array was properly sorted and then decided where the target could exist.

**What I learned:**  
- Binary Search on rotated arrays  
- How to identify the sorted half  
- Optimizing search problems to O(log n)  

---

## 💭 My thoughts  
This problem was interesting because normal binary search logic doesn’t work directly on rotated arrays.  

At first the conditions felt confusing, but after understanding how to identify the sorted half, the approach became much clearer.  

Good practice for improving binary search thinking.
