# 🚀 Day 26 - Set Matrix Zeroes

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Set Matrix Zeroes  
🔗 https://leetcode.com/problems/set-matrix-zeroes/description/

**What I did:**  
Tried to modify the matrix such that if an element is 0, its entire row and column become 0.

**Approach:**  
Used the first row and first column as markers to reduce extra space usage.

**What I learned:**  
- Matrix traversal techniques  
- Using existing matrix space for optimization  
- Careful handling of rows and columns  

---

## 💭 My thoughts  
This problem was a bit tricky because modifying the matrix directly can affect future checks.  

It took some time to understand how markers work, but the optimized approach was really clever.
