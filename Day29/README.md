# 🚀 Day 29 - Rotate Image

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Rotate Image  
🔗 https://leetcode.com/problems/rotate-image/

**What I did:**  
Tried to rotate a matrix by 90 degrees clockwise without using extra space.

**Approach:**  
1. Transposed the matrix  
2. Reversed each row  

**What I learned:**  
- Matrix transpose operation  
- In-place matrix manipulation  
- How breaking a problem into smaller steps simplifies the logic

## 💭 My thoughts  
This problem looked difficult at first, but the transpose + reverse trick made it much easier to understand.
