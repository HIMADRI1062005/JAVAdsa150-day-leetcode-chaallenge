🔗 https://leetcode.com/problems/concatenate-non-zero-digits-and-multiply-by-sum-ii/

## ✅ What I did

Solved the advanced version of the previous problem, where the goal was to construct a number using all non-zero digits, compute their sum, and return the required result while handling larger inputs efficiently.

## 💡 Approach

The solution follows a step-by-step process.

The overall idea was:

- Traverse the given number digit by digit.
- Ignore every zero digit.
- Concatenate only the non-zero digits to form a new number.
- Calculate the sum of those non-zero digits simultaneously.
- Multiply the constructed number by the calculated sum.
- Carefully handle larger input values while maintaining efficiency.

Instead of processing the digits multiple times, I completed the required operations in a single traversal.
