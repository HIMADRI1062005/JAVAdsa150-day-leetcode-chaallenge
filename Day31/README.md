# 🚀 Day 31 - Reverse Pairs

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Reverse Pairs  
🔗 https://leetcode.com/problems/reverse-pairs/

**What I did:**  
Tried to count important reverse pairs where `nums[i] > 2 * nums[j]`.

**Approach:**  
Used Merge Sort to efficiently count reverse pairs while sorting the array.

**What I learned:**  
- Modified Merge Sort technique  
- Divide and conquer approach  
- How sorting can help optimize counting problems
