## 🧩 Problems

### 1. Search Insert Position

🔗 https://leetcode.com/problems/search-insert-position/

## ✅ What I did

Found the position of a target value in a sorted array. If the target was not present, returned the index where it should be inserted.

## 💡 Approach

Used Binary Search to efficiently narrow down the search space.

If the target is found, return its index.
Otherwise, return the position where it can be inserted while maintaining the sorted order.

## 📚 What I learned

- Binary Search fundamentals
- Working with sorted arrays
- Finding insertion points efficiently

### 2. Minimum Cost of Buying Candies With Discount

🔗 https://leetcode.com/problems/minimum-cost-of-buying-candies-with-discount/

## ✅ What I did

Calculated the minimum amount needed to buy all candies while taking advantage of the discount offer.

## 💡 Approach

Sorted the candy prices in descending order.

For every three candies:
- Paid for the two most expensive candies
- Got the third candy for free

## 📚 What I learned

- Greedy Algorithm
- Sorting for optimization
- Maximizing benefits from given constraints
