# 🚀 Day 16 - Rotate Array

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Rotate Array  
🔗https://leetcode.com/problems/rotate-array/

**What I did:**  
Tried to rotate the array to the right by k steps.

**Approach:**  
Used the reverse method:
1. Reverse the whole array  
2. Reverse first k elements  
3. Reverse remaining elements  

**What I learned:**  
- Array reversal technique  
- In-place manipulation  
- Breaking a problem into smaller steps

## 💭 My thoughts  
This problem was interesting because there are multiple ways to solve it.
