# 🚀 Day 40 - Find the Duplicate Number

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Find the Duplicate Number  
🔗 https://leetcode.com/problems/find-the-duplicate-number/

**What I did:**  
Tried to find the duplicate number in an array without modifying the array and using only constant extra space.

**Approach:**  
Used Floyd’s Cycle Detection Algorithm (Slow and Fast Pointer).  
Treated the array like a linked list where each value points to the next index.

**What I learned:**  
- Floyd’s Cycle Detection Algorithm  
- How arrays can sometimes behave like linked lists  
- Optimized duplicate detection without extra space
