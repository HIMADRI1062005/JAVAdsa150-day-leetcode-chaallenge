# 🚀 Day 25 - Longest Consecutive Sequence

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Longest Consecutive Sequence  
🔗 https://leetcode.com/problems/longest-consecutive-sequence/

**What I did:**  
Tried to find the length of the longest consecutive sequence in an unsorted array.

**Approach:**  
Used a HashSet for quick lookup.  
Started counting only when the current number was the beginning of a sequence.

**What I learned:**  
- Efficient use of HashSet  
- Avoiding unnecessary repeated checks  
- Optimizing from sorting-based solutions to O(n)  

---

## 💭 My thoughts  
This problem was really interesting because the optimized solution was very different from the brute force idea I had initially.  

It felt satisfying to understand how HashSet can make the solution much faster.
