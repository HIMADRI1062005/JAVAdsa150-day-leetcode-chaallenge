# 🚀 Day 27 - Subarray Sum Equals K
Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Subarray Sum Equals K  
🔗 https://leetcode.com/problems/subarray-sum-equals-k/submissions/2001424131/

**What I did:**  
Tried to count the number of continuous subarrays whose sum equals k.

**Approach:**  
Used Prefix Sum with HashMap.  
Stored prefix sums and checked if `(currentSum - k)` already existed.


**What I learned:**  
- Prefix Sum technique  
- Using HashMap for optimization  
- How previous sums help solve subarray problems efficiently
