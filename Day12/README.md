## 🧩 Problem

### Remove Duplicates from Sorted Array  
🔗 https://leetcode.com/problems/remove-duplicates-from-sorted-array/post-solution/?submissionId=1988748956

**What I did:**  
Tried to remove duplicates from a sorted array in-place and return the number of unique elements.

**Approach:**  
Used two pointers. One pointer tracks unique elements, and the other scans the array.

**What I learned:**  
- Two pointer technique  
- In-place array modification  
- Importance of sorted property
