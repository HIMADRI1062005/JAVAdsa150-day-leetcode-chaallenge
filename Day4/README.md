## 🧩 Problem

### Max Consecutive Ones  
🔗 https://leetcode.com/problems/max-consecutive-ones/

**What I did:**  
Tried to find the maximum number of consecutive 1’s in a binary array.

**Approach:**  
Iterated through the array, counted consecutive 1’s, and reset the count whenever a 0 appeared.

**What I learned:**  
- How to track streak/count in an array  
- Simple iteration with condition handling  
- Importance of resetting variables correctly
