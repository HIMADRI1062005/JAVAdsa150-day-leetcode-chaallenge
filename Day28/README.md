## 🧩 Problem

### Spiral Matrix  
🔗 https://leetcode.com/problems/spiral-matrix/

**What I did:**  
Tried to traverse a matrix in spiral order.

**Approach:**  
Used four boundaries:
- top
- bottom
- left
- right

Traversed layer by layer while updating the boundaries.

**What I learned:**  
- Matrix traversal techniques  
- Managing multiple boundaries carefully  
- Step-by-step simulation approach
