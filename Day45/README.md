## 🧩 Problem

### Binary Search

🔗 https://leetcode.com/problems/binary-search/

**What I did:**
Searched for a target element in a sorted array and returned its index if found.

**Approach:**
Used the Binary Search algorithm to repeatedly divide the search space into two halves.

At each step:

* Calculated the middle index
* Compared the middle element with the target
* Moved left or right accordingly

This significantly reduced the number of comparisons compared to a linear search.

**What I learned:**

* Binary Search fundamentals
* Working with sorted arrays
* Reducing time complexity using divide-and-conquer
