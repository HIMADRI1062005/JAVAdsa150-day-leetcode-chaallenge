Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Longest Substring Without Repeating Characters  
🔗 https://leetcode.com/problems/longest-substring-without-repeating-characters/

**What I did:**  
Tried to find the length of the longest substring without repeating characters.

**Approach:**  
Used the Sliding Window technique with a HashSet.  
Expanded the window when characters were unique and shrank it whenever a duplicate character appeared.

**What I learned:**  
- Sliding Window technique  
- Dynamic window adjustment  
- Efficient substring handling using HashSet

## 💭 My thoughts  
This problem was really interesting because the window keeps changing dynamically based on duplicates.  

At first I was thinking about checking every substring, but then I understood how sliding window can optimize the solution efficiently.  

Definitely a very important pattern to learn for string problems.
