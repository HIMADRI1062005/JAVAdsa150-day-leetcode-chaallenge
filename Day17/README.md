Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Majority Element  
🔗https://leetcode.com/problems/majority-element/description/

**What I did:**  
Tried to find the element that appears more than ⌊n/2⌋ times in the array.

**Approach:**  
Used Boyer–Moore Voting Algorithm.  
Maintained a candidate and a count. If count becomes zero, update the candidate.

**What I learned:**  
- Boyer–Moore Voting Algorithm  
- How to find majority in O(n) time and O(1) space  
- Thinking beyond brute force and hash maps
