# 🚀 Day 13 - Single Number

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Single Number  
🔗https://leetcode.com/problems/single-number/submissions/1989393684/

**What I did:**  
Tried to find the element that appears only once, while every other element appears twice.

**Approach:**  
Used XOR operation. Since a ^ a = 0 and a ^ 0 = a, all duplicate numbers cancel out, leaving the single number.

**What I learned:**  
- Bit manipulation using XOR  
- How math properties can simplify problems  
- Writing optimal O(n) solution with O(1) space
