Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Maximum Subarray  
🔗 https://leetcode.com/problems/maximum-subarray/

**What I did:**  
Tried to find the contiguous subarray with the largest sum.

**Approach:**  
Used Kadane’s Algorithm.  
Kept track of the current sum and updated the maximum sum whenever needed.

**What I learned:**  
- Kadane’s Algorithm  
- Dynamic thinking in arrays  
- How resetting the sum helps optimize the solution
