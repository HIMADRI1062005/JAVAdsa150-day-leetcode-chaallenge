Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Contains Duplicate  
🔗 https://leetcode.com/problems/contains-duplicate/description/

**What I did:**  
Tried to check if any value appears at least twice in the array.

**Approach:**  
Used a HashSet to track elements. If an element already exists in the set, it means duplicate is found.

**What I learned:**  
- How HashSet helps in quick lookup  
- Difference between brute force and optimized approach  
- Writing clean and efficient code
