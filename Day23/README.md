Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Sort Colors  
🔗 https://leetcode.com/problems/sort-colors/

**What I did:**  
Tried to sort an array containing only 0s, 1s, and 2s without using extra space.

**Approach:**  
Used the Dutch National Flag Algorithm with three pointers:
- low for 0s
- mid for current element
- high for 2s

**What I learned:**  
- Three pointer technique  
- In-place sorting  
- Efficient array partitioning
