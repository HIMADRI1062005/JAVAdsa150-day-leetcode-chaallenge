# 🚀 Day 14 - Move Zeroes

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Move Zeroes  
🔗https://leetcode.com/submissions/detail/1990351451/

**What I did:**  
Tried to move all zeroes to the end of the array while maintaining the relative order of non-zero elements.

**Approach:**  
Used two pointers. One pointer tracks the position to place non-zero elements, and the other scans the array.

**What I learned:**  
- In-place array manipulation  
- Two pointer technique  
- Maintaining order while rearranging elements
