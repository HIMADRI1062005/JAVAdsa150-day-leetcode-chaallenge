# 🚀 Day 60 - Delete the Middle Node of a Linked List

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Delete the Middle Node of a Linked List

🔗 https://leetcode.com/problems/delete-the-middle-node-of-a-linked-list/

**What I did:**
Deleted the middle node from a linked list and returned the modified list.

**Approach:**
Used the fast and slow pointer technique to locate the middle node efficiently.

The main steps were:

* Finding the middle node using two pointers
* Keeping track of the previous node
* Removing the middle node by updating links
* Returning the updated linked list

**What I learned:**

* Fast and slow pointer technique
* Linked List traversal
* Node deletion operations
* Handling edge cases in linked lists

---

## 💭 My thoughts

This problem was a good practice for understanding how pointers work in linked lists.

The fast and slow pointer approach made it possible to find the middle node in a single traversal, which is much more efficient than counting nodes first.

A nice problem for strengthening linked list fundamentals and improving pointer manipulation skills.
