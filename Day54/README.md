## 🧩 Problem

### 3689. Maximum Total Subarray Value I

🔗 https://leetcode.com/problems/maximum-total-subarray-value-i/

## ✅ What I did

Calculated the maximum total value that can be obtained from a valid subarray.

## 💡 Approach

Analyzed the contribution of each subarray and tracked the maximum value throughout the traversal.

The main idea was:

- Evaluate valid subarrays
- Calculate their total value
- Keep updating the maximum answer whenever a better value is found

Careful handling of conditions was important to ensure the correct result.
