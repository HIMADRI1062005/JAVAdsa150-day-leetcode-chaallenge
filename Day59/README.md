# 🚀 Day 59 - Maximum Twin Sum of a Linked List

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Maximum Twin Sum of a Linked List

🔗 https://leetcode.com/problems/maximum-twin-sum-of-a-linked-list/

**What I did:**
Found the maximum twin sum in a linked list by pairing nodes from the beginning and the end of the list.

**Approach:**
Used an efficient approach to process the linked list and calculate the twin sums.

The main steps were:

* Finding the middle of the linked list
* Reversing the second half
* Comparing corresponding nodes
* Tracking the maximum twin sum

**What I learned:**

* Linked List traversal techniques
* Fast and slow pointer approach
* Reversing a linked list
* Optimizing space and time complexity

---

## 💭 My thoughts

This problem was a great combination of multiple linked list concepts.

The interesting part was realizing that reversing the second half of the list makes it easy to compare twin nodes directly.

A very good problem for strengthening linked list fundamentals and pointer manipulation skills.
