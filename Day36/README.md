# 🚀 Day 36 - Frequency of the Most Frequent Element

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Frequency of the Most Frequent Element  
🔗 https://leetcode.com/problems/frequency-of-the-most-frequent-element/

**What I did:**  
Tried to find the maximum possible frequency of an element after performing at most k increment operations.

**Approach:**  
Sorted the array and used the sliding window technique to maintain a valid window where all elements can be converted to the same value.

**What I learned:**  
- Sliding window optimization  
- Importance of sorting before processing  
- Efficient handling of window conditions
