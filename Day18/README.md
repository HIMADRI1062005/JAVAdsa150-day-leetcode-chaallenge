## 🧩 Problem

### Pascal's Triangle  
🔗 https://leetcode.com/problems/pascals-triangle/

**What I did:**  
Tried to generate Pascal’s Triangle up to a given number of rows.

**Approach:**  
Built the triangle row by row. Each element is the sum of two elements from the previous row.

**What I learned:**  
- Pattern-based problem solving  
- Working with nested lists  
- Understanding how previous results help build the next
