## 🧩 Problem

### Merge Intervals  
🔗 https://leetcode.com/problems/merge-intervals/

**What I did:**  
Tried to merge all overlapping intervals into a single interval.

**Approach:**  
Sorted the intervals first, then compared the current interval with the previous one to decide whether to merge or add separately.

**What I learned:**  
- Interval-based problem solving  
- Importance of sorting before processing  
- Handling overlapping ranges efficiently
