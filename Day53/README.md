# 🚀 Day 53 - Partition Array According to Given Pivot

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### 2161. Partition Array According to Given Pivot

🔗 https://leetcode.com/problems/partition-array-according-to-given-pivot/

## ✅ What I did

Rearranged the array according to a given pivot value while maintaining the relative order of elements.

## 💡 Approach

Used three groups to store elements:

- Elements smaller than the pivot
- Elements equal to the pivot
- Elements greater than the pivot

After traversing the array once, combined all three groups to form the final partitioned array.

This approach ensures the relative order of elements is preserved.

## 📚 What I learned

- Array partitioning techniques
- Maintaining relative order of elements
- Efficient array traversal
- Problem decomposition into smaller groups
