## 🧩 Problem

### Next Permutation  
🔗 https://leetcode.com/problems/next-permutation/submissions/1996808280/

**What I did:**  
Tried to rearrange numbers into the next greater permutation.

**Approach:**  
1. Found the first decreasing element from the end  
2. Swapped it with the next greater element  
3. Reversed the remaining part of the array  

**What I learned:**  
- Array manipulation techniques  
- Importance of observing patterns carefully  
- How reversing part of an array can help generate the next sequence
