## 🧩 Problem

### 3620. Network Recovery Pathways

🔗 https://leetcode.com/problems/network-recovery-pathways/

## ✅ What I did

Solved a graph problem that required finding valid recovery pathways in a network while satisfying the given conditions.

## 💡 Approach

The problem models the network as a graph where each connection represents a possible pathway.

The overall idea was:

- Represent the network using an adjacency list.
- Traverse the graph efficiently while maintaining the required conditions.
- Keep track of the best state for each node.
- Avoid revisiting unnecessary paths to improve performance.

By carefully exploring the graph, the solution efficiently identifies all valid recovery pathways.

## 📚 What I learned

- Graph traversal techniques
- Efficient state management
- Working with adjacency lists
- Optimizing graph exploration
