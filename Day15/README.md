## 🧩 Problem

### Max Consecutive Ones  
🔗 https://leetcode.com/problems/max-consecutive-ones/

**What I did:**  
Tried to find the maximum number of consecutive 1’s in a binary array.

**Approach:**  
Iterated through the array and kept counting consecutive 1’s. Reset the count whenever a 0 appeared.

**What I learned:**  
- Tracking sequences in arrays  
- Importance of maintaining a running count  
- Simple logic can solve problems efficiently
