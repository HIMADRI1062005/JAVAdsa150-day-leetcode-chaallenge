# 🚀 Day 93 - Find Greatest Common Divisor of Array

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### 1979. Find Greatest Common Divisor of Array

🔗 https://leetcode.com/problems/find-greatest-common-divisor-of-array/

## ✅ What I did

Solved a Number Theory problem that required finding the Greatest Common Divisor (GCD) of the smallest and largest elements in the array.

## 💡 Approach

The solution is straightforward and efficient.

The overall idea was:

- Traverse the array to find the minimum and maximum values.
- Apply the Euclidean Algorithm to compute the GCD of these two numbers.
- Return the resulting GCD.

Since the GCD of the entire array is determined by the smallest and largest values in this problem, there's no need for additional processing.

## 📚 What I learned

- Euclidean Algorithm
- Finding minimum and maximum efficiently
- Mathematical reasoning
- Simple and optimal implementation
