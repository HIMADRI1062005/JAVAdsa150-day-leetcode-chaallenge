## 🧩 Problem

### 3536. Maximum Product of Two Digits

🔗 https://leetcode.com/problems/maximum-product-of-two-digits/

## ✅ What I did

Solved a simple implementation problem that required finding the maximum product that can be formed using any two digits of the given number.

## 💡 Approach

The solution focuses on extracting and comparing digits efficiently.

The overall idea was:

- Extract every digit from the given number.
- Track the two largest digits while iterating.
- Compute the product of these two digits.
- Return the maximum product.

This approach avoids unnecessary sorting and processes the digits in a single pass.

## 📚 What I learned

- Digit extraction
- One-pass traversal
- Tracking maximum values
- Simple optimization techniques
