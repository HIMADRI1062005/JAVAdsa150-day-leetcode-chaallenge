# 🚀 Day 34 - Valid Palindrome

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### Valid Palindrome  
🔗 https://leetcode.com/problems/valid-palindrome/

**What I did:**  
Tried to check whether a string is a palindrome after removing non-alphanumeric characters and ignoring cases.

**Approach:**  
Used two pointers:
- One pointer from the beginning
- One pointer from the end

Skipped non-alphanumeric characters and compared lowercase characters.

**What I learned:**  
- String traversal techniques  
- Two pointer approach in strings  
- Handling special characters and case conversion
