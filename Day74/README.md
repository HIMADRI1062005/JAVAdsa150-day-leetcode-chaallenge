## 🧩 Problem

### 1967. Number of Strings That Appear as Substrings in Word

🔗 https://leetcode.com/problems/number-of-strings-that-appear-as-substrings-in-word/

## ✅ What I did

Solved a string matching problem where the goal was to count how many strings from the given array appear as substrings in a target word.

## 💡 Approach

The solution was based on straightforward string searching.

The process was:

- Traverse each string in the patterns array
- Check whether it exists as a substring inside the given word
- If it exists, increase the count
- Return the final count after checking all patterns

This approach is simple, clean, and works efficiently within the given constraints.

- String searching techniques
- Substring matching
- Array traversal
- Using built-in string methods effectively
