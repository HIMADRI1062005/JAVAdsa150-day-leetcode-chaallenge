## 🧩 Problem

### 3867. Sum of GCD of Formed Pairs

🔗 https://leetcode.com/problems/sum-of-gcd-of-formed-pairs/

## ✅ What I did

Solved a Number Theory problem that required calculating the sum of the Greatest Common Divisors (GCD) for all valid pairs formed according to the given conditions.

## 💡 Approach

The key idea was to efficiently compute the GCD values without repeatedly processing the same calculations.

The overall process was:

- Form the required pairs based on the problem statement.
- Compute the GCD for each valid pair using the Euclidean Algorithm.
- Accumulate the GCD values while traversing the pairs.
- Return the total sum after processing all pairs.

Instead of using unnecessary operations, the solution relies on the efficiency of the Euclidean Algorithm to compute GCD values quickly.
