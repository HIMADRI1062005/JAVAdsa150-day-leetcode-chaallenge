Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### 4Sum  
🔗 https://leetcode.com/problems/4sum/

**What I did:**  
Tried to find all unique quadruplets in the array that sum up to a target.

**Approach:**  
Sorted the array and fixed two elements, then used two pointers to find the remaining pair.

**What I learned:**  
- Extending 3Sum logic to 4Sum  
- Handling duplicates carefully  
- Combining sorting with two pointer technique
