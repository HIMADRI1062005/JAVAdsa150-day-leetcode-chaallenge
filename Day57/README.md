## 🧩 Problem

### 3559. Number of Ways to Assign Edge Weights II

🔗 https://leetcode.com/problems/number-of-ways-to-assign-edge-weights-ii/

## ✅ What I did

Calculated the number of valid ways to assign weights to the edges of a tree while satisfying the given constraints.

## 💡 Approach

The problem combines tree properties with mathematical counting.

The key idea was:

- Understand the relationship between nodes and edges
- Analyze the constraints carefully
- Use mathematical reasoning to count valid assignments efficiently
- Avoid brute-force generation of all possible assignments

By focusing on the structure of the tree, the solution can handle larger inputs efficiently.

## 📚 What I learned

- Tree-based problem solving
- Mathematical counting techniques
- Constraint analysis
- Efficient combinatorial thinking
