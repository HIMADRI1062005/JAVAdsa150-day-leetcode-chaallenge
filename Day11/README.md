# 🚀 Day 11 - 3Sum

Today I solved a medium level problem as part of my DSA journey.

## 🧩 Problem

### 3Sum  
🔗 https://leetcode.com/submissions/detail/1987746781/

**What I did:**  
Tried to find all unique triplets in the array that sum up to zero.

**Approach:**  
Sorted the array first, then used a two pointer approach for each element to find pairs that complete the sum.

**What I learned:**  
- Sorting helps simplify complex problems  
- Two pointer technique in combination problems  
- How to avoid duplicate triplets
