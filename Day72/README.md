## ✅ What I did

Solved a problem that required finding the maximum possible size of a valid subset while following the given conditions.

## 💡 Approach

The key idea was to analyze the frequency of each number and understand how they contribute to building a valid subset.

Instead of trying every possible combination, I focused on:

- Counting the occurrences of each element
- Identifying valid sequences based on the problem's rules
- Building the largest possible subset efficiently

Using a frequency-based approach helped avoid unnecessary computations and made the solution much more efficient.

- Frequency counting techniques
- Pattern recognition
- Greedy observations
- Efficient use of HashMap for counting
