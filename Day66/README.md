# 🚀 Day 66 - Maximum Ice Cream Bars

Today I solved one problem as part of my DSA journey.

## 🧩 Problem

### 1833. Maximum Ice Cream Bars

🔗 https://leetcode.com/problems/maximum-ice-cream-bars/

## ✅ What I did

Calculated the maximum number of ice cream bars that can be purchased using the given number of coins.

## 💡 Approach

Used a Greedy approach with Sorting.

The key idea was:

- Sort the costs array in ascending order
- Buy the cheapest ice cream bars first
- Continue purchasing until there are not enough coins left

Since buying cheaper bars first maximizes the total number of bars purchased, the greedy strategy guarantees the optimal answer.

## 📚 What I learned

- Greedy algorithm fundamentals
- Sorting as a preprocessing step
- Making locally optimal decisions
- Resource allocation problems

## 💭 My Thoughts

This was a straightforward Greedy problem.

The interesting part was recognizing that buying the cheapest ice cream bars first will always give the maximum count.
